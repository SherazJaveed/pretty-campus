# Pretty Campus - Privacy Policy

**Last updated: August 2026**

## Overview

Pretty Campus is a browser extension that enhances the Canvas LMS experience with dark mode, GPA calculator, task management, and productivity tools. We are committed to protecting your privacy.

## Data Collection

**Pretty Campus does NOT collect, store, or transmit any personal data to external servers.**

All data is stored locally on your device using Chrome's built-in storage API (chrome.storage.local). This includes:

- Your dark mode and theme preferences
- Task completion status and streak data
- Achievement badge progress
- Auto-saved text drafts
- Notification read/unread status
- Finals Mode timer settings

## What We Do NOT Collect

- No personal information (name, email, student ID)
- No login credentials or passwords
- No course content, grades, or assignment data
- No browsing history
- No analytics or usage tracking
- No cookies or tracking pixels

## Canvas API Access

Pretty Campus reads data from the Canvas LMS REST API solely to display your courses, grades, and assignments within the extension's interface. This data is cached locally for 5 minutes to improve performance and is never transmitted to any external server.

## Third-Party Services

Pretty Campus does not use any third-party analytics, advertising, or data collection services. There are no external API calls except to your own Canvas LMS instance.

## Data Storage

All data is stored locally on your computer using chrome.storage.local. You can clear all Pretty Campus data at any time by:

1. Right-clicking the Pretty Campus icon
2. Selecting "Remove from Chrome"
3. Or clearing extension data in Chrome Settings

## Permissions

Pretty Campus requests the following Chrome permission:

- **storage**: To save your preferences and settings locally on your device

## Children's Privacy

Pretty Campus does not knowingly collect information from children under 13.
